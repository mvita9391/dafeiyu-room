# 本地验收清单

整理日期：2026-11-04。此文档对应当前 Node.js + Three.js + SQLite 项目，替代早期单 HTML 原型的自测记录。

## 自动检查

```bash
npm test
npm run build
npm run check:public
npm run self-check
```

`npm run check` 合并前三项。`self-check` 使用临时数据库、临时端口和真实 MCP SDK 验证授权、建造、行动、重启及撤权，不应访问个人存档。

本轮文档整理前的代码基线通过了 150 项测试及 MCP 自检。此数字只是当时的记录；以后以实际命令输出为准，不作为固定测试数量要求。

## 玩家与画面

- WASD 下一帧响应，连续转向平滑；松键和窗口失焦后停止，不等待网络返回。
- 门口按正确方向可以切换场景，不会刚到新场景就被弹回。
- 室内视角保持固化规则，户外水平旋转并跟随角色。
- 左下角为心情、饱食、精力，精力显示一位小数；没有把精力标为亲密。
- 吃白饭原地执行，能看见饭碗和手臂动作；完成后收起饭碗。
- 睡觉沿床方向躺下；动作结束后能恢复正常姿势。
- 点击电脑前的椅子，能够找到可达位置并坐下，朝向与座面高度正确。
- 坐下完成后继续保持坐姿，不因短计时结束而掉到地面；移动时安全起身。

自动测试验证状态和部分展示逻辑；外观、遮挡、模型穿插与设备性能仍需实际打开页面检查，不从测试通过推断任意设备都达到固定帧率。

## 编辑、保存与目录

- 四个初始场景和新建场景可进入编辑模式，分类、滚动、拖动、旋转、删除与撤销正常。
- 新目录包含秋千、野餐桌、遮阳伞、花箱、花拱门和鸟浴盆。
- 点击秋千可以坐下，人物跟随座面轻摆；改变家具旋转与缩放后仍能对齐。
- 普通摆放可以保存，刷新和重启后恢复；保存失败不能假显示成功。
- 九块农田、保护区域和门前通道不能被建设操作侵占。
- 新安装读取发布初始布局；已有存档不会被新版默认配置覆盖。

不要在个人存档中自动执行破坏性测试。测试重置、默认发布导出和迁移时使用临时路径。

## MCP 接入验收

1. 页面复制的地址是入口 5200 的 `/mcp`，不包含凭证。
2. 标准授权后能发现 18 个工具，首次 `world_enter {}` 成功。
3. 填错世界名得到 `WORLD_SELECTION_INVALID` 和该授权可用的世界；无效或撤销凭证仍为 401。
4. 能观察地图与目录、取得租约、跨场景行动并查到真实终态。
5. 建设预览不会改变画面，应用后才显示并保存。
6. 主人接管后旧租约不能继续操作；撤权后不能继续调用。
7. 断开客户端但保留服务，已接受的有限动作仍可完成；重连能查询结果。
8. 事件读取与确认分开；历史缺口按恢复回执处理，不跳过未读事件。
