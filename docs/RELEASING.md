# 提交与发布检查

公开版以四个默认场景和公开角色为基础。常规提交保留游戏代码、对外文档、初始布局及清单列出的资源。

| 内容 | 公开范围 |
| --- | --- |
| 大肥鱼角色 | 公开角色只保留带动画的 `resources/character/models/Dafeiyu.glb`。Vite 按角色清单打包。 |
| 精选家具模型 | `resources/polyfork/` 中清单列出的 146 个模型、缩略图及 CC BY 4.0 署名。 |
| 界面图片和音效 | `public/` 中的界面图和许可文本，以及 `resources/audio/manifest.json` 列出的音频。 |
| 本机内容 | `.cache/` 中的全量模型、素材包及导入备份，`data/` 中的存档与密钥，以及桌面壳和作者工作文件留在本机。 |

新模型需要更新对应清单及 SHA-256。初始布局引用精选库模型时，模型和缩略图须在公开清单里，确保干净克隆能加载。其他私有素材用于个人存档，不作为初始世界发布。参见[存档与初始世界](WORLD-SAVES.md)。

提交前执行：

```bash
npm ci
npm run check
git status --short
git diff --cached --stat
```

`npm run check` 会运行测试、构建网页，并检查已跟踪文件和未被忽略的提交候选。检查通过后，核对暂存区里包含本次需要发布的清单、资源和文档。更新布局、模型、许可或授权说明时，在没有个人存档和本机素材的目录中验证一次新游戏。

旧角色模型和制作文件归档在本机 `_archive/character-legacy/`。当前版本只发布运行模型。旧提交里的文件仍可从 Git 历史取得。
